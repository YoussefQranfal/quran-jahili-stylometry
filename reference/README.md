# `reference/`

This directory holds the **original** source-study repository this project
reproduces and extends:

> Salem Othman & Youssef Qranfal (Wentworth Institute of Technology),
> "Hidden Stylistic Schools of Pre-Islamic Poetry: A Computational Analysis
> Using Sentence Embeddings," submitted to IEEE ICAD 2026.
> Original repository: <https://github.com/SalemOthman/hidden-poetic-schools>

It is included **for attribution and reference only** — this is their
code, not this project's own work. Nothing in this folder was written or
modified by this project; it is copied here unedited (minus their own copy
of `data/poems.db`, to avoid a third redundant copy of that file — see the
top-level `data/README.md` for the one copy this repository ships and
uses).

This project's own reproduction of their pipeline lives in
`notebooks/00_reproduction_of_source_study/`, and its own from-scratch
reimplementation package (written independently, not copied from this
reference repo) lives in
`notebooks/00_reproduction_of_source_study/reimplementation_package/`.

The `output/` subfolder here still contains the original authors'
own example CSV outputs, shipped as part of their repository — these
describe *their* run of *their* pipeline, not a run performed as part of
this project. See their own `README.md` and `LICENSE` (both preserved
here) for their license terms and citation.

# Supporting Reports Index

These are narrative write-ups produced at various points in the project's
history — either shorter companion articles or per-experiment-batch
summary reports. They are supplementary reading; the authoritative,
citable results are the notebooks' own printed output (see the root
`README.md`'s experiment index and `docs/KNOWN_ISSUES.md`). Where a number
here appears to disagree with a notebook's own output, trust the notebook.

| File | What it is |
|---|---|
| `clustering_article.pdf` / `.docx` | Short, popular-style companion article summarizing the main clustering study's reproduction and its confound-controlled results. |
| `combined_clustering_report.pdf` | Results summary for Experiments 1 & 2 (Qur'an-as-one-author / surahs-as-separate-authors mixed into the 260-poet pool). |
| `experiment8_report.pdf` | Results for Experiment 8 (35 well-documented poets + 114 surahs as separate authors) — the strongest confound-controlled separation result in the project (0/114 mixed clusters). |
| `extended_analysis_report.pdf` | The six follow-up questions answered directly on the Experiment 1/2 results (which surah was the Experiment 2 outlier, count-vs-text-size weighting, full cluster membership, poets-only re-clustering, and the two exclusion/size-matching reruns). |
| `professor_questions_report.pdf` | Answers to a professor's specific follow-up questions on the Experiment 8 follow-up and Experiments 9-12 (which surahs/hizb are in which cluster, outlier identities, etc.). |
| `final_summary_report.pdf` | Summary of the complete 2x2 grid: Qur'an-as-one vs. Qur'an-as-114-surahs, crossed with all-260-poets vs. well-documented-poets-only (Experiments 1, 2, 7, 8). |
| `quran_stylometry_report.md` | Early markdown-format project summary, used as raw material when drafting the root `README.md`. |

The full narrative report for Experiments 14 and 15-30, and a structural
comparison of lexical richness / word-length / verse-ending consistency,
exist only as plain-text files, in `output/reports/` (`experiments_13_30_report.txt`
and `structural_analysis_report.txt`), not as PDFs here — their PDF
versions weren't included in this repository because they couldn't be
cleanly separated from unrelated content elsewhere in the same source
document; the plain-text versions have that content fully removed.
